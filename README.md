# ❤️ Heart Disease Analysis Dashboard – Power BI 📊

🔍 **Project Overview**

This project is an interactive **Heart Disease Analysis Dashboard** developed using **Microsoft Power BI**. The dashboard transforms healthcare data into meaningful insights through interactive visualizations, KPIs, and filters.

### 🚀 Key Features

* 🧹 **Data Cleaning & Transformation** using Power Query
* 📊 **Interactive Dashboard** with charts, KPIs, and visualizations
* 🧮 **DAX Measures** for calculations and analysis
* 🔎 **Interactive Filters & Slicers** for detailed analysis
* ❤️ **Heart Disease Analysis** based on patient and health-related factors
* 📈 **Trend & Pattern Analysis** to identify important insights
* 💡 **Data-Driven Insights** using Power BI visualizations

### 🛠️ Tools & Technologies

* 📊 **Microsoft Power BI**
* 🔄 **Power Query**
* 🧮 **DAX**
* 📈 **Data Visualization**
* 🔍 **Data Analysis**

### 🎯 Project Objective

The main objective of this project is to analyze heart disease-related data and convert raw data into **clear, interactive, and meaningful insights** that can support data-driven understanding and decision-making.
